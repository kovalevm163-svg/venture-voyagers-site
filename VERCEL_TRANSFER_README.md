# Venture Voyager -> Vercel Transfer Package

## Included files
- index.html
- styles.css
- script.js
- vercel.json

## Deploy (Dashboard)
1. Open Vercel dashboard.
2. Create New Project.
3. Choose **Import Third-Party Git Repository** OR drag/drop this folder/zip.
4. Framework Preset: **Other**.
5. Build Command: *(leave empty)*
6. Output Directory: *(leave empty)*
7. Deploy.

## Connect domain
After deploy, add:
- venture-voyagers.com
- www.venture-voyagers.com

Then set DNS at Squarespace:
- `@` A `76.76.21.21`
- `www` CNAME `cname.vercel-dns.com`

Keep all Google Workspace mail records unchanged.
